#Прототип музыкального онлайн-магазина

Консольное приложение интернет-магазина музыкальных носителей, разработанное на **C# / .NET**.

Приложение позволяет работать с пользователями, просматривать каталог виниловых пластинок и компакт-дисков, формировать заказы и сохранять данные пользователей в Excel.

Проект разработан в рамках курсовой работы с акцентом на применение принципов объектно-ориентированного программирования.

## Возможности

* регистрация пользователей;
* удаление пользователей;
* поиск пользователя по номеру телефона;
* просмотр списка зарегистрированных пользователей;
* просмотр каталога товаров;
* фильтрация товаров по типу;
* оформление заказа;
* добавление нескольких товаров в заказ;
* проверка наличия товара;
* автоматическое уменьшение количества товара после покупки;
* расчет итоговой стоимости заказа;
* отмена заказа;
* просмотр истории заказов пользователя;
* сохранение пользователей в Excel;
* восстановление данных пользователей из Excel;
* валидация пользовательских данных.

## Каталог

В магазине представлены два типа музыкальных носителей:

* виниловые пластинки;
* компакт-диски.

Для всех товаров хранится:

* ID;
* название альбома;
* исполнитель;
* цена;
* количество товара в наличии.

Для виниловых пластинок дополнительно хранится цвет пластинки.

## ООП

Архитектура приложения построена с использованием основных принципов объектно-ориентированного программирования.

### Абстракция

Общие характеристики товаров вынесены в абстрактный класс:

```text
Goods
```

Он содержит общие свойства:

```text
ID
Album
Band
Price
AmountInStock
```

а также абстрактный метод:

```text
Info()
```

### Наследование

От `Goods` наследуются два типа товаров:

```text
Goods
├── Record
└── CD
```

`Record` представляет виниловую пластинку, а `CD` — компакт-диск.

### Полиморфизм

Классы `Record` и `CD` переопределяют метод `Info()` и формируют собственное представление информации о товаре.

### Инкапсуляция

Данные покупателей и товаров контролируются через свойства.

Например, при создании пользователя выполняется проверка:

* имя и фамилия не могут отсутствовать;
* имя и фамилия не могут состоять из числа;
* номер телефона должен соответствовать допустимому формату;
* номер должен содержать 11 цифр.

Также приложение не позволяет зарегистрировать двух пользователей с одинаковым номером телефона.

## Основные классы

### `Customer`

Представляет покупателя интернет-магазина.

Хранит:

* имя;
* фамилию;
* номер телефона;
* список заказов.

Класс позволяет добавлять новые заказы и просматривать историю заказов пользователя.

### `Goods`

Абстрактный базовый класс товара.

Содержит общие характеристики продукции и логику изменения количества товара на складе.

### `Record`

Наследник `Goods`, представляющий виниловую пластинку.

Дополнительно содержит информацию о цвете пластинки.

### `CD`

Наследник `Goods`, представляющий компакт-диск.

### `Order`

Представляет заказ пользователя.

Позволяет:

* добавлять товары;
* выводить содержимое заказа;
* подсчитывать количество товаров;
* рассчитывать итоговую стоимость;
* отменять заказ.

### `Shop`

Основной класс магазина.

Управляет:

* пользователями;
* каталогом;
* виниловыми пластинками;
* компакт-дисками;
* поиском товаров и пользователей;
* сохранением и загрузкой пользовательских данных.

### `DataBase`

Отвечает за сохранение данных пользователей в Excel-файл и их последующее чтение.

Для работы с Excel используется библиотека **FreeSpire.XLS**.

## Оформление заказа

Для оформления заказа пользователь вводит номер телефона, привязанный к аккаунту.

После этого приложение:

```text
Проверяет наличие пользователя
          ↓
Показывает каталог
          ↓
Пользователь выбирает товар по ID
          ↓
Проверяется наличие товара
          ↓
Товар добавляется в заказ
          ↓
Количество на складе уменьшается
          ↓
Рассчитывается стоимость заказа
          ↓
Заказ сохраняется в истории пользователя
```

В один заказ можно добавить несколько товаров.

Также пользователь может отменить формирование заказа.

## Работа с данными

Данные пользователей могут сохраняться в:

```text
DataBase.xlsx
```

Для работы с Excel используется библиотека:

```text
FreeSpire.XLS
```

Приложение поддерживает:

* запись пользователей в файл;
* чтение пользователей из файла;
* восстановление списка пользователей для дальнейшей работы.

## Структура проекта

```text
kursovaya/
└── online_shop/
    ├── online_shop.sln
    │
    └── online_shop/
        ├── Customer.cs
        ├── DataBase.cs
        ├── Goods.cs
        ├── Order.cs
        ├── Program.cs
        ├── Shop.cs
```

### Назначение файлов

* `Customer.cs` — модель покупателя и его заказов;
* `Goods.cs` — модель товаров, виниловых пластинок и CD;
* `Order.cs` — формирование и обработка заказа;
* `Shop.cs` — основная бизнес-логика магазина;
* `DataBase.cs` — сохранение и чтение пользователей из Excel;
* `Program.cs` — консольное меню и пользовательские сценарии.


## Результат

В результате разработано консольное приложение, моделирующее основные процессы интернет-магазина: управление пользователями и ассортиментом, формирование заказов, контроль наличия товаров, расчет стоимости и сохранение пользовательских данных.

Проект демонстрирует практическое применение классов, наследования, абстракции, полиморфизма, инкапсуляции, коллекций и работы с внешними файлами в C#.
